# 如何使用 MaynorAI 文章同步工作台

**MaynorAI 文章同步助手**支持将一篇文章一键同步到 **23 个平台**的草稿箱。在默认设置下，系统**仅负责创建或更新草稿，不会直接发布**；只有当你主动开启「**同步后直接发布**」选项时，才会尝试执行发布操作。

**工作台地址**：[https://editor.maynor1024.live/](https://editor.maynor1024.live/)  
**产品介绍**：[https://product.maynor1024.live/](https://product.maynor1024.live/)

![产品介绍页](https://upload.maynor1024.live/file/1795057062551_08-product-hero.png)

在费用方面，日常的**写作、保存草稿以及同步到各平台草稿箱均为免费使用**；而涉及 AI 生成的功能，包括「**AI 润色**」「**文章插图**」和「**做封面**」，则需要付费使用。

## 1. 安装浏览器扩展

多平台同步功能需要依赖本机浏览器扩展来实现。你的各平台**账号和 Cookie 数据只保留在自己的浏览器本地**，不会上传或出现在工作台网页上。

打开工作台后，点击页面顶部的「**扩展连接**」，按照侧栏给出的说明依次完成安装：

1. 将扩展安装包下载到本地并完成解压。
2. 在 Chrome 浏览器中打开扩展管理页，或在 Edge 浏览器中打开对应的扩展管理页。
3. 在扩展管理页中，找到并开启右上角的「**开发人员模式**」。
4. 点击「**加载已解压的扩展程序**」按钮，浏览并选择刚才解压后的文件夹（注意文件夹内必须包含 `manifest.json` 文件）。
5. 打开扩展弹窗，保存页面中自动生成的**连接密钥**。这一步骤只需操作一次；后续如果遇到扩展更新，只需在扩展管理页点击「**重新加载**」即可，不必再次重新选择文件夹。

如果你使用的是 Edge 浏览器，也可以选择先在商店中安装；待商店审核通过后，同样可以改为从 Chrome 应用商店进行安装。

当扩展安装并成功连接后，工作台顶部会显示**已连接**状态以及当前的**扩展版本**。如果页面仍然提示「未检测到扩展」，可以点击「**重新检测**」按钮，或者直接刷新页面再试。

## 2. 登录，使用云端文章夹

在**未登录**状态下，草稿仅会保存在当前使用的浏览器中；**登录账号**后，页面左侧的「**云端文章夹**」会自动加载你的云端文章列表，即使更换其他设备也能继续写作。

需要更新目录时，直接点击左侧标题「**云端文章夹**」即可手动刷新列表。

![登录后的工作台和云端文章夹](https://upload.maynor1024.live/file/1795057064341_01-workbench.png)

## 3. 写作、预览和保存

工作台页面中间是主编辑区，支持直接使用 **Markdown 语法**写作，你可以随时切换到「**预览**」视图，实时查看最终的排版效果。顶部工具栏还提供了**标题、列表、链接、保存以及历史版本**等常用操作，方便随时调用。

内容写完后，点击右下角的「**保存草稿**」按钮即可保存。需要注意的是，未登录时草稿只保存在本机；登录后则会自动同步到你的云端文章夹。

![写作与预览](https://upload.maynor1024.live/file/1795057066003_03-writing.png)

## 4. 使用 AI 润色正文

登录账号后，点击顶部工具栏里的「**AI 润色**」。在弹出的面板中，先选择需要使用的模型，再输入一句具体的润色要求（例如「语气更口语，保留我的小节结构和表格」），确认后点击「**开始润色**」即可。

当前可选的模型包括 **Claude Opus 5.5、GPT-6.2 Sol、Gemini 4 Hydrogen 和 Grok 4.7**，这几款均为专业版模型。润色结果会**一边生成一边实时显示**，无需干等整篇文章全部处理完成。

日常写作本身**不会扣除任何积分**；只有当你点击开始润色时，才会消耗对应的次数或积分。

![AI 润色面板](https://upload.maynor1024.live/file/1795057071401_04-ai-polish.png)

## 5. 做封面和文章插图

在顶部同一排工具栏里，还配备了「**做封面**」和「**文章插图**」两项功能。

使用做封面功能时，先选定所需比例（例如 16:9），接着可以按需填写封面文案，也可以上传参考图，最后点击「**生成 16:9 封面**」按钮；而文章插图功能则会按照正文内容的需要为你插入配图。这两项功能均会**消耗套餐内的图片额度**，如果尚未开通套餐，则需要先开通后方可使用。

![做封面](https://upload.maynor1024.live/file/1795057070129_05-cover-or-illustrations.png)

## 6. 同步到各平台草稿箱

当确认扩展处于**已连接**状态、且文章也已**保存**后，点击右下角的「**同步到草稿箱**」，或者直接点击工具栏里的「**同步任务**」，即可准备发起同步。

在随后弹出的窗口中，勾选需要同步的目标平台和对应账号，核对确认后再点击「**创建同步任务**」（默认情况下不会直接发布）。如果列表中某个平台显示「**未能确认**」，请先回到浏览器扩展里登录该平台账号，再点击「**重新检测**」更新状态。

针对部分特殊平台需要注意：**GitHub** 需要在浏览器扩展中预先添加 Token；**X 长文**则会同步至 [X Articles](https://x.com/compose/articles)，这要求你具备付费的 X 方案，且扩展程序在同步时只会尽量为你保存草稿，不会代你点击「发布」按钮。

如果暂时不需要执行同步，直接点击弹窗上的「**关闭**」即可退出，系统不会创建任何任务。

![同步到草稿箱](https://upload.maynor1024.live/file/1795057077141_06-sync-modal.png)

## 7. 查看同步历史

点击工具栏中的「**历史任务**」入口，可以随时查看最近的同步任务执行结果。如果你此前还没有创建过任何同步任务，这里则会显示「暂无任务」。

![历史任务](https://upload.maynor1024.live/file/1795057078807_07-history.png)

## 收费说明

- **免费功能**：日常写作、保存草稿以及将文章同步到各平台草稿箱，全部免费使用。
- **付费功能**：AI 润色、文章插图与做封面功能，需要付费或消耗额度使用。
- **套餐定价**：提供三档套餐选择，分别为**入门版 $4.99（首次开通 $0.99）**、**创作者版 $9.9** 以及**专业版 $24.9**；其中**专业版**可以使用上述各款旗舰模型。

需要说明的是，本产品**并非各内容平台的官方产品**；同时，只要你未主动勾选「**同步后直接发布**」，系统就绝对不会直接公开发布你的文章。
